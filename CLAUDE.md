# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Quick Commands

- **`pnpm dev`** - Run TypeScript directly without compilation (uses ts-node)
- **`pnpm build`** - Compile TypeScript to JavaScript in `./dist` directory
- **`pnpm format`** - Format all code using Prettier
- **`pnpm format:check`** - Check code formatting without making changes

## Project Structure

This is a minimal TypeScript template project. The structure is straightforward:

- **`src/`** - All TypeScript source files live here
- **`dist/`** - Compiled JavaScript output (generated by `pnpm build`)
- **`tsconfig.json`** - TypeScript compiler configuration with strict mode enabled
- **`package.json`** - Node.js project metadata and dependencies

## Technology Stack

### Core

- **TypeScript 5.9.3** - Language and compiler
- **ts-node 10.9.2** - Allows running TypeScript files directly
- **@types/node 25.3.0** - Type definitions for Node.js APIs

### Build & Code Quality

- **Prettier 3.8.1** - Code formatter for consistent style
- **pnpm 10.26.1** - Package manager (see `packageManager` field in package.json)

### Dependencies

- **es-toolkit 1.44.0** - Utility library with modern JavaScript functions

## Development Notes

- TypeScript strict mode is enabled, so all files must have proper type annotations
- Source code should be written in the `src/` directory with `.ts` extension
- Use `pnpm dev` for quick iteration and testing during development
- Use `pnpm build` before deployment or when you need compiled JavaScript output

## Code Formatting

Prettier is configured for consistent code formatting:

- Configuration is in `prettier.config.js`
- Run `pnpm format` to format all files
- Run `pnpm format:check` to verify formatting without changes
- Files in `.prettierignore` are excluded from formatting
